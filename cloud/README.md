# Intro to cloud computing


## Why cloud computing ?

Pay as you go to test system before fully commiting 

## What is Cloud computing?

on-demand delivery of IT resource over the internet with pay as you go pricing


## Client-server model 

A <b>Client</b> can be a web browser or desktop app that a person interacts with to make request to computer servers.

A <b>Server</b> can be services such as Amazon Elastic Compute Cloud (EC2), a type of virtual server
